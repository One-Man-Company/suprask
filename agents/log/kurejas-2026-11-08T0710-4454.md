## 1. Ką keičiau

`agents/run.py`:

- `changed_files()` — pašalinta `[:40]` riba. Sąrašas nebekerpamas; tikrų failų
  skaičių riboja pats commit'as, o `git add` paleidžiamas dalimis, kad ilgas
  sąrašas neužkimštų argumentų eilutės (ARG_MAX).
- `changed_files()`, `git_snapshot()`, `changed_list()`, `publish()` —
  `git status --porcelain` → `git status --porcelain -uall`. Be `-uall` git
  visiškai nesutrackintą katalogą rodo **viena eilute** (`?? agents/log/`), todėl
  į sąrašą patekdavo katalogas vietoj failų, o skaičiai meluodavo (nauja pamoka
  LL-44, žr. §5).
- `stage()` (nauja) — `git add -A -- <keliai>` po 400 kelių. `-A` būtinas, kad
  ištrintas failas būtų komituotas kaip trynimas.
- `_tracked()` (nauja) — atskiria ištrintą trackinamą failą nuo išnykusio
  netrackinamo. Anksčiau `(ROOT / f).exists()` tyliai numesdavo trynimą.
- `revert()` — `git checkout --` irgi dalimis (ta pati ARG_MAX riba, kai
  atmetamų failų šimtai).
- `publish()` — `detail` dabar skaičiuoja **tai, kas tikrai pateko**, o ne tai,
  ko prašyta: `Paskelbta N failų`, o jei kas nors išnyko ar liko nešvaru —
  `, K nebuvo vietoje (...)` / `, K liko nešvarūs (...)`.
